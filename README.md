# Выводы эксперимента
ArrayList быстрее работает при доступе к элементам по индексу, потому что его элементы хранятся в массиве и к ним можно обращаться напрямую.

При добавлении и удалении элементов в начале LinkedList обычно работает быстрее, так как ему не нужно сдвигать остальные элементы. В ArrayList при таких операциях приходится перемещать элементы массива.

При вставке в середину у ArrayList происходит сдвиг элементов, а LinkedList сначала находит нужное место в списке. Поэтому результат зависит от стоимости обеих операций.

При добавлении в конец обе коллекции показывают хорошее время. У ArrayList иногда требуется увеличить размер внутреннего массива, а LinkedList создаёт новый узел для элемента.
